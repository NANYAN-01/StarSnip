## 1. 背景与问题

日常工作中大量信息以"图片形态"存在:聊天截图、报表截图、PDF 扫描页、软件界面里的数字。现有做法是:
1. 截屏 → 2. 打开某个 OCR 网页(上传有隐私风险、限流、收费)→ 3. 复制结果 → 4. 手动整理。

已有基础设施(本次已落地):

- 远程 Ollama 服务 `<内网主机>:11434`(Ollama 0.40.16,推理快);
- 实测选型:`glm-ocr`(文本/表格 100%,2.5s)、`unlimited-ocr`(chat + 坐标框,1.6s)、`qwen2.5vl`(复杂版面);
- 一个可复用的 MCP 服务 `ollama-ocr`(已注册到 mimo)。

**缺口**:没有"随手可用"的图形入口。缺一个常驻托盘的小工具:一个热键就能截图取字。

## 2. 目标与成功指标

**目标**:本地常驻、单热键触发、2 秒内出结果的截图 OCR 工具,数据不出内网,并能与现有 MCP/agent 体系复用同一后端。

| 指标 | 目标值 |
|---|---|
| 热键 → 结果可复制的端到端耗时(p95) | ≤ 3s(单区域截图,文本类) |
| 文字识别准确率(内部测试集) | ≥ 98%(干净截图) |
| 常驻内存 | ≤ 120MB |
| 冷启动 | ≤ 2s |
| 离线/后端不可用 | 明确提示,不静默失败;可重试 |
| 隐私 | 图片仅内网传输,不留云端;历史可一键清空 |

## 6. 功能详述

### F1 全局热键截图(P0)
- 默认 `Ctrl+Alt+O`(可改);`Esc` 取消。
- 触发后全屏变暗遮罩,拖拽选框;支持:
  - 拖拽任意矩形;`空格` 或点击窗口 = 识别整窗;`Ctrl+A` = 全屏(当前显示器)。
  - 松手即识别(不必再点确认);选区尺寸 < 8×8 视为误触取消。
  - 多显示器:遮罩覆盖所有显示器,支持跨屏拖拽。
- 截图时不隐藏本工具窗口(浮窗出现前不抢焦点)。

### F2 结果浮窗(P0)
- 出现在选区附近(空间不足则调整位置),显示:
  - 顶部:识别模式、模型名、耗时、状态;
  - 中部:可编辑文本区(等宽字体,表格模式渲染为表格);
  - 底部按钮:复制全部、复制选中、切换模型重试、保存、关闭。
- `Esc` 关闭;`Ctrl+C` 复制;窗口失焦不自动关闭(避免误关),但可配置。
- 复制后 0.8s 内显示"已复制"toast。

### F3 识别模式(P0/P1)
| 模式 | 说明 | 默认模型 |
|---|---|---|
| 纯文本(P0) | 原样行文本 | glm-ocr |
| 表格(P1) | markdown 表格 + CSV 复制按钮 | glm-ocr(行对齐好) |
| 结构化 JSON(P1,实验) | 按字段模板抽取(如发票:金额/日期/收款人) | qwen2.5vl |
| 版面还原(P2) | 保留 bbox,可导出带位置的 JSON | unlimited-ocr(chat) |

模式自动建议:识别结果里 `|` 或 `\t` 密度高/含"合计/总计"→ 提示切换表格模式。

### F4 双模型交叉校验(P1,差异化亮点)
- 同时请求 `glm-ocr` 与 `unlimited-ocr`(或用户指定两个),并行执行。
- 逐行比对,差异行在浮窗中高亮(黄色),鼠标悬停显示另一模型的结果。
- 目的:①发现漏字(如合计金额丢失);②给用户选择依据;③积累错误样本。
- 成本控制:仅在用户点"校验"时触发,默认单模型。

### F5 历史记录(P1)
- SQLite 本地库 `%APPDATA%\ScreenOCR\history.db`,记录:时间、缩略图路径、识别模式、模型、耗时、文本、来源(热键/剪贴板/PDF)。
- 主窗口(托盘右键→历史)支持:关键词搜索、按日期筛选、复制、删除、清空全部、打开缩略图。
- 默认保留最近 500 条;可配置保留天数;缩略图与文本均只存本地。

### F6 图片预处理(P1)
- 自动:长边 > 1280px 时等比缩到 1280(glm-ocr 分辨率甜区,已实测 1500+/2000px 会丢细数字)。
- 手动开关:2× 放大(小字)、对比度增强、灰度、暗色主题反色。
- 识别结果差时,浮窗提供"预处理后重试"一键动作。

### F7 剪贴板与拖拽(P1)
- 监听剪贴板:复制了图片时,托盘气泡提示"识别这张?"(可关闭)。
- 拖拽图片/PDF 到托盘图标或主窗口直接识别。

### F8 翻译(P2)
- 识别后可选"翻译":调用 `translategemma:4b` 或 `qwen3.5:4b`,输出上下对照(原文/译文)。
- 用途:英文界面、外文合同。

### F9 导出与插入(P1/P2)
- 导出 `.txt` / `.md` / `.csv`(表格)/ `.json`(结构化)。
- P2:导出 `.xlsx`(表格)、把结果"插入到上一个活动窗口的光标处"(模拟粘贴)。

### F10 批量 PDF(P2)
- 复用现有 `ocr_pdf` 逻辑:拖入 PDF → 逐页识别 → 结果按页分组,可合并导出。

### F11 MCP / Agent 集成(P2)
- 本工具与 `ollama-ocr` MCP 共用后端;**新增** `screen_capture_ocr(region=null)` 工具:让 agent 主动截屏并识别。
- 需要用户在一次会话内授权"允许 agent 截屏",避免后台偷拍。

### F12 托盘与设置(P0)
- 托盘菜单:截图识别、历史、设置、暂停监听、退出。
- 设置项:后端 URL、默认模型、热键、保留条数、开机自启、剪贴板监听开关、浮窗失焦行为。
- 首次运行引导:检测后端连通(自动测 `/api/tags`),失败给出手动配置入口。

## 9. 技术方案

### 架构
```
┌─────────────── ScreenOCR 客户端 (PySide6) ───────────────┐
│ 全局热键(keyboard)  → 截图(Win32/BitBlt + Qt 遮罩)      │
│ 预处理(Qt/OpenCV: 缩放/对比度)                          │
│ OCR 客户端(复用 ollama 调用层,支持 generate/chat)       │
│ 后处理(表格转 md/csv、坐标清洗、diff 校验)              │
│ 浮窗 UI / 历史 SQLite / 托盘 / 设置 JSON                 │
└───────────────────────┬──────────────────────────────────┘
                        │ HTTP (内网)
                 ┌──────▼──────┐
                 │ Ollama 服务 │ <内网主机>:11434
                 │ glm-ocr / unlimited-ocr / qwen2.5vl │
                 └─────────────┘
```

### 模型路由策略(内置,可覆盖)
| 场景 | 模型 | 调用方式 |
|---|---|---|
| 默认文本/表格 | `glm-ocr:latest` | generate |
| 极速 / 需要坐标 | `richardyoung/unlimited-ocr:latest` | chat(+坐标清洗) |
| 复杂版面 / 结构化字段 | `qwen2.5vl:7b` | generate |
| 翻译 | `translategemma:4b` / `qwen3.5:4b` | generate |
| 禁用 | `longwayxu/xiaomi-ocr-0`(丢标题页脚) | — |

### 复用现有资产
- `D:\030\ocr\ocr_mcp_server.py`:OCR 调用层、坐标清洗、PDF 渲染、`max_side_px` 逻辑可直接抽成 `ocr_core.py` 共享。
- MCP 包(`桌面\ollama-ocr-mcp.zip`)保持独立,不做破坏性改动;新增功能放在工具侧。

### 数据模型(history.db)
```sql
CREATE TABLE history (
  id INTEGER PRIMARY KEY,
  created_at TEXT NOT NULL,      -- ISO8601
  source TEXT NOT NULL,          -- hotkey|clipboard|drop|pdf|agent
  mode TEXT NOT NULL,            -- text|table|json|layout
  model TEXT NOT NULL,
  elapsed_ms INTEGER,
  text TEXT NOT NULL,
  thumb_path TEXT,               -- 缩略图相对路径
  meta TEXT                      -- JSON: 尺寸/预处理/bbox 等
);
CREATE INDEX idx_history_created ON history(created_at);
```

## 10. 隐私与合规

- 图片仅发往内网 Ollama;不写第三方云。
- 历史与缩略图仅本地存储,路径在设置中可见;提供"清除全部"。
- Agent 截屏需显式授权,且在浮窗/托盘显示"正在截图"指示。
- 日志不记录识别原文。
