## 关键实现决策

1. **零依赖**:截图用 GDI(BitBlt/DIB section),缩放用 StretchBlt(HALFTONE),PNG 编码用 zlib 手写——避开 Pillow 未安装的问题,也为日后分发减负。
2. **DPI 感知**:启动即 `SetProcessDpiAwareness(2)`,否则多屏/缩放下选区偏移。
3. **截图时机**:热键触发时**先全屏截图**再显示遮罩,避免把遮罩本身截进去。
4. **分辨率上限**:送识别前长边缩到 `max_side_px=1280`(实测 glm-ocr 在 1500+/2000px 会丢合计金额等细数字)。
5. **双模型并发**:`ocr_core.call_many` 用线程并发;`disagreements()` 以"主结果行是否出现在其他模型输出"为准,交叉校验窗口高亮差异行。
6. **事件线程模型**:热键线程与 OCR 线程只向 `queue` 投递事件,Tk 主线程轮询消费——避免跨线程操作 UI。
