# ScreenOCR 工作日志

> 按时间倒序记录:决策、实现、问题、测试结果。

## 2026-11-20(M2–M5 开发)

### 规划
- 接收 4 条新增需求:剪贴板图片 + 图片目录保存、Toast 提示、AI 排版(Word/TXT/XLSX/MD)、VL+通用模型双模型协作。
- 确定 M2–M5 拆分,写入 `docs/开发计划.md`。

### M2 实现
- 新增 `clipboard_image.py`(Win32 CF_DIB)、`screenfiles.py`(Pictures 保存)、`toast.py`(浅色轻提示)。
- App 在框选完成后执行副作用:保存 PNG → 写剪贴板 → Toast「已保存」,随后并行开始 OCR。
- 测试:剪贴板可读回正确宽高 DIB;PNG 落盘;Toast 400ms 自动消失;M2 集成测试通过。

### M3 实现
- 新增 `mdblocks.py`(标题/段落/列表/表格块解析)、`writers/docx.py`、`writers/xlsx.py`(纯 stdlib OOXML)、`ai_writer.py`(LLM 排版 + 分发)。
- 结果窗口新增「AI 排版 ▾」菜单:Word / TXT / XLSX / MD;导出线程 + Toast + 状态栏路径。
- 关键优化:发现若不显式传 `think:false`,qwen3.5:4b 会先“思考”导致 65s;显式关闭后 **3.9~4.1s**,质量不变(表格完整)。
- 测试:writers OOXML 结构校验通过;export 四格式均生成;e2e 增加 docx 导出阶段验证。

### M4 实现
- `mcp_server.py` 暴露 `screen_capture_ocr(region, prompt, model)`;`--mcp` 按需导入 FastMCP(保持桌面端零依赖)。
- PyInstaller `--onefile --noconsole` 打包 19.5MB;**冻结环境配置从 exe 同目录读取**(`sys.frozen` 分支)。
- exe 冒烟:`--capture-test` 生成 276KB PNG,退出码 0。
- MCP 冒烟:客户端成功列出 `screen_capture_ocr`。


### 用户反馈修复(托盘不可见 / 自定义快捷键)
- 定位「没有托盘」:正在运行的实例 PID 4364 启动于 10:54,早于 M1 托盘代码,属旧进程;重启即可。
- 托盘加固:NOTIFYICONDATAW 升级为完整 V4 结构 + NIM_SETVERSION(4) + NIF_SHOWTIP;新增 Shell_NotifyIconGetRect 可见性诊断(rect 落日志);wait_rect 处理 Shell 时序抖动;启动 0.9s 后 Toast 提示「图标若不可见请点 ^」。
- 诊断入口:--tray-test、--diagnose(后端/托盘/热键一次体检,结果写日志);日志 %APPDATA%\ScreenOCR\screenocr.log(1MB 轮转);托盘菜单加「打开日志」;Tk 回调异常统一记日志并弹窗。
- 自定义快捷键:hotkey_ui.py 按键捕获对话框(GetAsyncKeyState 判修饰键,Tk keysym 转配置格式),实时重注册、失败回滚、写回 config.json;托盘菜单「设置快捷键…」入口;成功 Toast 提示。
- 验证:test_tray 通过(rect=1508,1030,30,50);test_hotkey_settings 通过;测试套件 19 项全绿;exe 重新打包后 --diagnose 退出码 0。
