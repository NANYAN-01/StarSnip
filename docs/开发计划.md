## 1. 需求来源

- 第 1 轮:PRD(`D:\030\ocr\PRD-screenshot-ocr.md`)——截图 OCR 工具,双模型校验、历史、表格模式、内网私有。
- 第 2 轮补充需求(本计划直接纳入):
  1. 截图后图片**同时写入系统剪贴板**和用户的**「图片」系统目录**;
  2. 操作完成后弹**浅色轻提示 Toast**(“已保存”),停留片刻自动消失;
  3. 新增 **AI 排版** 功能,提供【Word】【TXT】【XLSX】【MD】导出;
  4. 选择格式后,调用本地 Ollama 的 **VL 模型 + 通用大模型**,智能识别并排版,生成对应文件交付用户。

## 2. M2 设计:截图增强

### 2.1 剪贴板图片
- 通过 Win32 `OpenClipboard/EmptyClipboard/SetClipboardData(CF_DIB)` 写入截图(BGRA → 自底向上 DIB,alpha 置 255)。
- 无第三方依赖;失败不影响 OCR 主流程,仅 Toast 提示。

### 2.2 保存到「图片」目录
- 默认路径:`%USERPROFILE%\Pictures\ScreenOCR\ScreenOCR_YYYYMMDD_HHMMSS.png`。
- 使用已知文件夹 `Pictures`(中文系统为「图片」);配置 `image_dir` 可覆盖。
- 文件名带毫秒避免同秒冲突。

### 2.3 Toast
- tkinter `Toplevel` 无边框、置顶、浅色背景(`#f7f7f7`+浅边框),底部右侧淡入淡出,默认 2s 自动消失。
- 场景:截图已保存、文件已导出、剪贴板失败等。

### 2.4 配置新增
`save_image`(默认 true)、`image_dir`、`clipboard_image`(默认 true)、`toast_ms`(默认 2000)。

## 3. M3 设计:AI 排版

### 3.1 处理链路
```
截图 OCR 文本(已有)
   ↓  通用大模型(qwen3.5:4b)整理
规范 Markdown(标题/段落/表格,事实不增删)
   ↓  本地转换器(确定性,不调模型)
Word(.docx) / TXT(.txt) / XLSX(.xlsx) / MD(.md)
```
- VL 模型负责「识别」,通用模型负责「排版」,文件生成由本地转换器完成——避免让 LLM 直接写二进制格式带来的不可控。
- 若排版失败,回退使用原始 OCR 文本继续导出,不中断流程。

### 3.2 文件写入器(零依赖)
- `writers/docx.py`:最小 OOXML(Content_Types / rels / document.xml),支持标题、段落、无序列表、表格(带边框)。
- `writers/xlsx.py`:最小 SpreadsheetML,每个 Markdown 表格一个工作表(表头首行),纯文本内容单列;数字识别为数值单元格(`t="n"`)。
- TXT:Markdown 降级为纯文本;MD:直接保存。

### 3.3 UI
- 结果窗口新增「AI 排版 ▾」菜单:Word / TXT / XLSX / MD。
- 导出中禁用按钮并显示状态;完成后 Toast「已导出:xxx.docx」,状态栏显示完整路径。
- 导出目录默认 `%USERPROFILE%\Documents\ScreenOCR`,可配置;提供「打开导出目录」。

## 4. M4 设计:生态与分发

### 4.1 MCP 工具
- `screenocr --mcp` 启动 stdio MCP 服务(FastMCP v1,按需导入,不影响零依赖桌面运行)。
- 工具:`screen_capture_ocr(region="", prompt="")`:region 空=全屏,支持 `x,y,w,h`;返回识别文本。
- 依赖 `mcp<2`(与既有 ollama-ocr MCP 一致)。

### 4.2 打包
- PyInstaller `--onefile --noconsole`,入口 `screenocr_launcher.py`。
- 冻结环境配置查找修正:`sys.frozen` 时从 exe 同目录读取 `config.json`。
- 交付:exe + config.json 说明;仍可用源码方式运行。

## 5. M5 质量收尾

- 全量测试(单元 + UI + 端到端 + exe 冒烟)。
- 性能优化目标:热键→出字 p95 ≤3s(热后端);截图保存不阻塞识别;导出 ≤5s。

## 7. 风险

| 风险 | 应对 |
|---|---|
| LLM 排版改写事实 | 提示词强约束“不增删事实”;转换前保留原始文本可追溯(历史记录) |
| 表格结构被 LLM 破坏 | 导出前用 `tablefmt` 校验;解析失败回退原始 OCR 文本段落 |
| 剪贴板被其他程序占用 | `OpenClipboard` 重试 3 次,失败仅提示不阻塞 |
| exe 被杀软误报 | 提供免安装 zip + 源码运行替代;必要时签名 |
